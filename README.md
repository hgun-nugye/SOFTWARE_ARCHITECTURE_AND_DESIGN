# Software Architecture and Design

This repository contains study materials, lecture notes, and practice examples from coursework at **Nha Trang University**, under the academic guidance of **PhD. Huỳnh Tuấn Anh**.

## Contents
- Fundamentals of software architecture
- Design patterns and principles
- System modeling and documentation
- Case studies and practice exercises
- Best practices in scalable software design

## Purpose
The repository is intended to support learning and practice for students studying **Software Architecture and Design** at the university level, providing both theoretical foundations and practical applications.

## Technologies
- UML (Unified Modeling Language)
- Design extension (Plant4UMLidea)
- Java (for implementation examples)
- IntelliJ IDEA (IDE)
